# 论文计划 — 起草前填写

> **怎么用**：中文或英文都行，写你顺手的。**不知道就写 `?`**——`?` 是下一次和 agent 讨论的议程，
> 比一个看似合理的猜测有用得多。不要留空；空表示"还没想过"。
>
> 第 1–7 节在动笔之前填；第 8 节（摘要）**最后填**。

## 1. 研究问题

**RQ，一句话**（一句读者可以不同意的话）：

>

**如果这个问题不解决，我们现在还不能判断什么？**

>

**一旦回答，哪一个认识或选择会因此改变？**

>

**研究哪个对象、在什么条件下、判断哪种关系？**

>

| 自检 | 答案（是 / 否 / ?） |
|---|---|
| 一个懂行的读者可能给出不同答案吗？ | |
| 它有没有点名"对象"和"判断"？ | |
| 答案是不是本来就显而易见？ | |
| 用你能拿到的证据能回答吗？ | |

如果这篇论文有两个问题，写在这里，并说明为什么它们值得放在一篇里：

>

## 2. 故事五环（五句话）

每环一句。它们分别变成引言（1–2）、方法（3）、评估（4）、讨论（5）。

| # | 环 | 你的句子 |
|---|---|---|
| 1 | 问题从哪来？（领域现在不能做的那个判断） | |
| 2 | 为什么值得回答？（哪个决定会变） | |
| 3 | 怎么回答？（方法的理由，不是步骤） | |
| 4 | 证据支持到哪一步？（测了什么、没测什么） | |
| 5 | 现在多知道了什么？（认识的变化及其边界） | |

**哪一环最弱，为什么？**

>

## 3. 结构选型

| 方案 | 形态 | 选择 |
|---|---|---|
| A. 方法优先 | 引言 → 背景 → 方法 → 一个评估 → 讨论 | ☐ |
| B. 按 RQ 分章 | 引言 → 背景 →（RQ1 方法+结果）→（RQ2 方法+结果）→ 讨论 | ☐ |

**为什么选这个而不是另一个？**

>

**相关工作放哪？** ☐ 方法之前 ☐ 评估之后 ☐ 不单列
**为什么？**
